## 🚀 Introduction
Barcode Generator for Windows is a desktop application built to convert your data into clean, standards-compliant barcodes. Instead of hand-drawing codes or juggling online converters, you type or import values and let the app render them accurately. It works equally well for a one-off code and for a full labeling run, which makes it a dependable barcode code generator for shipping, retail, and asset tracking on a Windows PC.

## ✨ Highlights

### Create the codes you need
- **1D barcodes** — Generate the common linear symbologies used across retail and logistics.
- **2D and QR codes** — Produce 2D barcode formats and QR codes for links, text, and contact data.
- **Flexible captions** — Add human-readable text beneath each code when you need it.

### Scale and output
- **Random or sequential batches** — Fill a run with random values or an incrementing sequence in one pass.
- **Print and export** — Save codes as images or print sheets ready for your label stock.

1. Start Barcode Generator and pick a 1D or 2D/QR barcode type.
2. Enter a single value or define a random or sequential batch.
3. Set the size, quiet zone, and caption for your labels.
4. Preview the codes to confirm they scan cleanly.
5. Print the sheet or export the codes as image files.
